* **Course:** BCA
* **Semester:** 3

## Objective

To learn photo editing techniques, including cropping, brightness and contrast adjustment, colour correction, and removal of small unwanted spots.

## Tools Used

* Crop Tool
* Move Tool
* Spot Healing Brush Tool
* Brush Tool
* Brightness/Contrast Adjustment
* Color Balance Adjustment
* Layers Panel

## Steps

1. Open Adobe Photoshop.
2. Open a photograph using File → Open.
3. Duplicate the original layer using Ctrl + J.
4. Use the Crop Tool to remove unwanted areas.
5. Adjust brightness and contrast to improve the image.
6. Use Color Balance to correct the colours if required.
7. Use the Spot Healing Brush Tool to remove small unwanted spots.
8. Compare the edited image with the original image.
9. Save the editable file in PSD format.
10. Export the final edited image as a JPG.

# Practical 03 – Travel Poster Design Using Layers and Layer Masks

## Student Details

* **Name:** Vansh Deshwal
* **Roll Number:** CU25260251
* **Course:** BCA
* **Semester:** 3

## Objective

To create an attractive travel poster by combining multiple photographs and using layers, layer masks, and text tools in Adobe Photoshop.

## Tools Used

* Move Tool
* Transform Tool
* Layer Mask
* Brush Tool
* Text Tool
* Layers Panel
* Shape Tool

## Steps

1. Open Adobe Photoshop.
2. Create a new document with a size of 1200 × 1600 pixels.
3. Open three travel photographs, such as mountains, rivers, and landscapes.
4. Place the photographs on the poster canvas.
5. Arrange each photograph on a separate layer.
6. Use Ctrl + T to resize and position the photographs.
7. Add layer masks to the photographs.
8. Use a soft brush on the layer masks to blend the images.
9. Use the Text Tool to add the heading "TRAVEL TO MANALI".
10. Add a subtitle, such as "Explore the Beauty of Nature".
11. Adjust the font, size, colour, and position of the text.
12. Save the editable file in PSD format.
13. Export the final poster as a JPG image.

# Practical 06 – Complete Photoshop Project: Promotional Poster

## Student Details

* **Name:** Vansh Deshwal
* **Roll Number:** CU25260251
* **Course:** BCA
* **Semester:** 3

## Objective

To create a professional promotional poster by combining Photoshop skills learned in Modules 1 and 2.

## Tools Used

* Move Tool
* Quick Selection Tool
* Brush Tool
* Text Tool
* Shape Tool
* Layer Mask
* Adjustment Layers
* Filters
* Blending Modes
* Layer Styles
* Custom Brushes

## Steps

1. Create a new document with suitable dimensions for a promotional poster.
2. Choose a theme, such as a College Event, Workshop, Hackathon, Cultural Fest, or Photography Exhibition.
3. Create an attractive background using colours, gradients, or shapes.
4. Add relevant images using File → Place Embedded.
5. Use an advanced selection technique, such as the Quick Selection Tool, to select the main subject.
6. Apply a Layer Mask to control the visibility of the selected subject.
7. Add at least one Adjustment Layer to improve the colours or brightness.
8. Apply at least one Photoshop filter to an image or design element.
9. Apply at least one Blending Mode, such as Screen, Multiply, or Overlay.
10. Apply at least one Layer Style, such as Drop Shadow or Outer Glow.
11. Use a custom brush or brush-based effect to decorate the poster.
12. Add the event name, date, time, venue, and organizer or department name using the Text Tool.
13. Use attractive typography and arrange all elements neatly.
14. Maintain at least three layers and give them meaningful names.
15. Save the editable project as a PSD file.
16. Export the final promotional poster as a JPG file.
